# Physical AI

This repository will contain practical projects for learning how software can perceive, control, and interact with the physical world.

## What will be built here

Future projects will explore:

- Robot design and browser-based 3D simulation
- Robot arms, mobile robots, and autonomous systems
- Computer vision and sensor-driven applications
- Motion planning, navigation, and obstacle avoidance
- Digital twins and simulation-ready 3D environments
- AI models that make decisions using physical-world data
- Connections between high-level software and robot hardware
- OpenUSD, NVIDIA SimReady, Isaac Sim, and related Physical AI tools

Each project will have its own folder containing source code, setup instructions, technical notes, references, and a live demo when available.

## Current project

### Robot Easy

Robot Easy introduces robotics to people from software and IT backgrounds. It generates a robot blueprint, recommends components, explains the software architecture, and provides an interactive 3D robot-arm workcell.

- [Project source and documentation](./robot-easy/)
- [Live application](https://ashishchaturvedi7-robot-easy.static.hf.space)
