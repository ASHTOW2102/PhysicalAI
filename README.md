# Physical AI Projects

A growing collection of projects exploring robotics, simulation, and software that interacts with the physical world.

## Projects

### 1. Robot Easy

A beginner-friendly robot design tool for people from software and IT backgrounds. It generates hardware and software blueprints and includes an interactive 3D robot-arm workcell with inverse kinematics.

- [Source code and instructions](./robot-easy/)
- [Live Hugging Face demo](https://ashishchaturvedi7-robot-easy.static.hf.space)
- [NVIDIA SimReady Central reference](https://huggingface.co/blog/nvidia/simready-central-assets-robotics-ai-factories)
